# 设置、开局生命周期与 Guide 定向重构

## 模块与规则归属

- `src/client/modules/global-settings.js`：设置页通过 `createGlobalSettingsModule` 注入 React、RPC 和独立编辑区块。父级拥有首次设置快照；开局默认值只在首次挂载时读取预设和偏好目录，保存后采用服务端返回的规范化值。模型保存失败保留原选择。完整注册入口由真实 React/浏览器验证，不再截取模型设置函数来模拟 Hook。
- `src/client/modules/frame-lifecycle.js`：统一等待文档 body、取消等待、文档变化后的幂等挂载，以及输入发送的有效性、并发去重、成功后单次完成、失败重试和销毁。`legacy-composer.js` 保留 DOM、slash 与宿主输入的适配；模块脚本仍只执行一次。开局预览发送沿用可见文档和当前请求的归属检查。
- `lib/domain/conversation-guides.js`：统一游玩会话查询、当前状态内的添加/删除/加载和保存到独立库。`guide-content.js` 拥有文本、名称、数量校验；库编辑与本局编辑共用校验。新增内容超过 2000 字明确拒绝，不再静默截断。前端按 ID 删除；旧客户端的序号在进入修改前解析为目标身份，不再把越界序号钳制到其他条目。加载保留当前指导并跳过重复内容，修改库不会反向改写已加载的游戏内容。

本次不改变模型请求结构、提示词前缀或历史存储格式。用户原有的三个前端未提交文件差异保留在工作区，不纳入这些提交。
