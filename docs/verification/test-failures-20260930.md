# 全量测试失败修复（2026-09-30）

基于 `496faec2` 后的当前工作区修复上一轮全量测试的 32 项失败。此次仅修改测试和测试夹具，不删除或跳过任何用例，不修改生产代码。

## 原因与修复

- 结算恢复及台账测试通过 VM 执行真实 `runSettlement`，却遗漏其新增的 `createSettlementProgressGuard` 依赖。注入真实模块，恢复原有结算、重启恢复、迟到写入与取消路径的验证。
- 长期偏好和回退菜单测试仍断言旧控件名称、旧元素结构；更新为当前控件，保留 RPC 参数、禁用状态、不可回退原因与独立重新生成入口检查。
- 开场预览新增全局设置读取，旧夹具缺少 RPC。补充设置响应，等待其完成后检查预览准备状态，继续验证去重、模式隔离与失败退出。
- 人物设计 Skill 的边界文案变更，更新断言为现有“不向前台追加设计说明”。
- 全局设置开关在异步保存成功后才更新受控值，Playwright `check()` 会过早检查状态。改为点击、等待保存完成，再断言开关与同级设置；保留保存失败恢复检查。
- 生图测试的两秒轮询把模型启动时间混入阻塞验证。夹具按实际 HTTP 请求到达发出事件，最多等待 30 秒；请求挂起后的状态查询、关闭和取消仍保留原有一秒响应限制。
