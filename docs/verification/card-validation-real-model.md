## 手测发现并修复

- 卡片工作台准备请求、展示会话和结束回合时，不再强制解析待修复卡片，避免坏 JSON 在模型调用前堵住校验工具。游玩模式仍严格读取卡片。
- 协同通知版本加入 cardPath/cardName，使首次保存绑定变化能立即通知侧栏。
