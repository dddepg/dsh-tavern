# 原生游玩的动态世界书快照

EJS（包括只读取配置的表达式）、随机条目及其他动态条目不进入固定世界书前缀。条目仍正常参与激活、预算和模板求值，只在发送阶段比较最终文本。

采用整份动态区域快照，保留条目顺序及跨条目的 XML 标签。首次发送完整内容；文本相同不重复发送；变化时在当前请求尾部追加完整新版本，并声明此前版本失效。全部清空或禁用时追加一次失效说明。内容按当前状态解释，相同文本不代表新的重复事件。

前后台各自读取当前 Session 有效消息面的最后一份快照，不在 Chat 中提前保存“已发送”标志。前台快照独立于会被清理的本轮指引；后台快照随任务消息保存。回退、放弃重生成、失败清理与分支沿用原生消息面边界；历史导入按轮次重建。若压缩移除了快照，下一次请求补发完整当前状态。

快照只追加，不修改历史版本。既有会话升级后，原本在系统前缀中的 EJS 会迁到尾部，因此首次请求的系统前缀会变化。普通固定条目的原有更新逻辑、其他上下文清理逻辑，以及酒馆兼容模式不属于此机制。

验证：`tests/worldbook-snapshot.test.mjs` 覆盖状态变化、失效、恢复、分支、失败重试、重生成清理、压缩补发，以及真实 DSH Agent 的前台请求前缀和后台重启去重。测试使用脚本模型，不产生付费请求；未测量真实供应商缓存命中率。
