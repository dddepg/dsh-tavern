产品概览

DSH Tavern 是运行在 DeepSeek Harness（DSH）上的文字游戏与资源工作台。

DSH Tavern 是什么

DSH Tavern 是一个以文字为主的 AI 角色扮演与故事游玩工具，提供类似 SillyTavern 的文字游戏体验。导入一张人物卡，就可以进入它设定的世界，与角色对话、采取行动，让故事继续发展。

它运行在 DeepSeek Harness（简称 DSH）上：DSH 提供模型连接和运行环境，Tavern 提供人物卡、游玩界面、资源工作台和相关功能。你现在看到的是使用文档，实际游戏需要安装后打开。

两种主要使用方式

模式你在做什么常见用法
游玩模式参与故事，与角色互动自由输入行动、选择候选；也可以绑定小说或大纲，沿着剧本玩
卡片模式与 Agent 讨论和修改资源把卡中不喜欢的设定改掉，调整世界书和预设，或从剧本中提取新人物卡

两种模式可以独立使用。不需要先学会制卡才能玩，也不需要重做一张卡才能调整自己的体验。

打开后，界面大概是什么样

整体是“左侧找对话，中间阅读或操作，右侧看状态与资源”的布局。本页界面截图使用专门创作的公开样例，不包含私人对话或配置；点击图片可放大查看。

区域游玩时制作或修改内容时
左侧栏新建游戏，继续和整理已有故事新建工作台，继续之前的资源讨论
中间主区域阅读剧情、输入行动，选择候选或重写正文告诉 Agent 修改要求，讨论方案，确认修改
右侧栏查看剧情指导、人物状态和剧本进度查看人物卡库、世界书库、剧本库和预设库，编辑或引用资源

人物卡可能自带正文美化和状态栏，所以不同卡的展示细节会不同。主体始终是文字故事，插画是可选的高级能力。

一次游玩是怎样的

  1. 选一张喜欢的人物卡，预览并确认开场。
  2. 阅读故事，输入自己的行动或对白；没想好时可以看看候选建议。
  3. 发送行动，等待新的剧情与状态结果。
  4. 继续下一轮；不满意时可以重写、回退，或添加持续剧情指导。

例如，你可以直接写“我先不回答，走到窗边看看街上的情况”，不必按固定选项行动。

可以带来什么内容

支持导入酒馆人物卡、世界书和预设，也可以导入小说、剧本或大纲。正则、MVU 和前端美化的具体支持范围，见酒馆生态兼容。

想改变内容时，进入卡片模式，告诉 Agent 哪些不喜欢、希望怎样调整，以及哪些需要保留。它也可以从素材中抽取人物与设定来制作新卡。

开始前需要准备什么

  • 一台可运行 DSH 的设备，按安装与启动选择桌面版或命令行版。
  • 一个可用的文字模型服务，准备服务地址、模型名称和所需的 API 密钥；模型调用可能产生费用。
  • 一张想玩的 PNG / JSON 人物卡；也可以安装后再通过卡片模式制作。

不用先导入外部预设。用户画像、文生图和其他高级设置都可以先跳过，遇到需要时再查。

安装与启动

先安装 DSH Tavern，再配置一个可用的文字模型。桌面版和命令行版选择一种即可。

选择安装方式

方式适合谁支持平台
纯小白一键安装下载后直接运行，无需手动准备运行环境仅 Windows x64
DSH Desktop 安装先安装 Desktop，再通过 DSH 终端安装酒馆Windows x64、macOS
命令行版希望通过浏览器访问、自己管理服务Windows、macOS、Linux / WSL2
Android 实验版愿意自行排错的手机用户通过 DSHA 尝试安装，不保证一定可用

桌面版与命令行版选择一种即可，不要同时运行。下方命令会下载并执行本项目安装脚本，请在确认项目来源可信后运行；网页本身不会自动执行安装。

命令行版独立安装固定的 DSH 0.1.2-rc.1。Desktop / DSHA 复用宿主，要求内置 DSH 版本完全匹配，不匹配时停止安装；请自行下载安装适配版本。

纯小白一键安装（仅 Windows x64）

下载 Windows 一键在线安装 EXE

  1. 下载后双击运行，首次启动保持联网。
  2. 安装器自动准备 Desktop 2.0.5 和当前兼容的最新版酒馆，无需另装 Node.js 或 DSH Desktop。
  3. 打开酒馆后，在“设置 → 模型”配置模型，再导入人物卡。

已有安装和数据会保留，之后可在酒馆界面检查更新。这是在线安装程序，不是无需网络的离线整包。

DSH Desktop 安装（Windows / macOS）

  1. 安装适配版本 DSH Desktop 2.0.5（内置 DSH 0.1.2-rc.1）。打开 历史版本下载页面，找到 v2.0.5，展开 Assets，下载适合自己系统的安装包；不要下载 Source code。内置 DSH 版本不匹配时会停止安装，请使用适配版本。
  2. 启动后，打开 设置 → 通用设置，点击窗口顶部的 打开 DSH 终端。
  3. 在这个终端里，运行你所用平台的命令。

Windows

powershell
$env:DSH_TAVERN_HOST='desktop'; $tavernInstaller=[Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://cdn.jsdelivr.net/gh/flizzywine/dsh-tavern@main/install.ps1')); Invoke-Expression $tavernInstaller

macOS

bash
curl -fsSL https://cdn.jsdelivr.net/gh/flizzywine/dsh-tavern@main/install.sh | DSH_TAVERN_HOST=desktop sh

安装完成后，重启 DSH Desktop，进入 设置 → 桌面设置，在右侧 Profile 列表点击 tavern；旁边显示 当前 即为选中。看到酒馆界面后，继续下方的“配置模型并开始第一局”。桌面版由 DSH Desktop 管理启停，不需要另外启动命令行服务。

方式二：命令行版

先准备 Node.js 22.19 或更高版本。建议安装 Git，便于增量更新；没有 Git 时安装器会回退到 ZIP 下载。不论电脑是否已有 DSH，每次安装都会下载独立的固定版本，不复用或修改全局 DSH。首次安装会询问目录：1 默认目录 ~/.dsh-tavern/；2 当前目录（直接回车选这一项）；3 其他完整路径。程序、独立运行时和游戏数据存入所选目录，命令入口及包管理器缓存可能在目录外。Node.js 使用系统版本。

Windows PowerShell

powershell
$env:DSH_TAVERN_HOST='cli'; $tavernInstaller=[Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://cdn.jsdelivr.net/gh/flizzywine/dsh-tavern@main/install.ps1')); Invoke-Expression $tavernInstaller

macOS / Linux / WSL2 终端

bash
curl -fsSL https://cdn.jsdelivr.net/gh/flizzywine/dsh-tavern@main/install.sh | DSH_TAVERN_HOST=cli sh

安装器会安装依赖、启动酒馆，并在首次安装时打开网页。如果关闭了页面，可以重新打开：

bash
dsh-tavern open

也可以运行以下命令查看服务状态与访问地址：

bash
dsh-tavern status

请使用显示的完整访问地址；它可能包含鉴权 token，不要分享给别人。这里只打开浏览器页面，不是重新安装。

配置模型并开始第一局

  1. 在左侧栏底部打开 设置 → 模型。
  2. 按服务要求填写 API 密钥、服务地址并选择文字模型。
  3. 导入 PNG / JSON 人物卡，选择新建游玩。
  4. 预览开场、按需设置玩家称呼，然后发送第一条行动。

能够看到新生成的正文，就完成了首次游玩。不需要同时配置外部预设、用户画像或文生图。详细步骤见配置文字模型和第一次游玩。

关机后如何重新打开

桌面版：重新启动 DSH Desktop，确认当前 Profile 是 tavern。

命令行版：先启动服务，再打开页面。

bash
dsh-tavern start
dsh-tavern open

需要停止或重启时，分别使用以下命令：

bash
dsh-tavern stop
dsh-tavern restart

关闭浏览器页面不等于停止服务；电脑关机则会结束本机服务。这里说的是游戏服务，和本地文档预览地址 127.0.0.1:4173 不同。

更新与重新安装

首次安装、更新或重新安装，都可以运行上面对应宿主、对应平台的安装命令。一般无需先卸载；安装器更新程序文件，保留人物卡、对话、配置、自定义工具和 Skill。

重新安装前仍建议备份数据。更新沿用已安装位置。重新运行 CLI 安装命令时，请在原安装根目录执行，或设置 DSH_TAVERN_CLI_HOME 指向原位置；不要无意中安装到新目录。Desktop、CLI 和 DSHA 数据各自独立，切换安装方式不会自动同步。

命令行版也可使用：

bash
dsh-tavern update

这个命令更新 Tavern，不是升级 DSH 本体。桌面版从设置顶部打开 DSH 终端，重新运行桌面安装命令，完成后重启 Desktop。若内置更新失败，也可用对应安装命令更新安装器和程序。

Android：通过 DSHA 安装

适配版本：DSHA 1.2.0-rc1.4（预览版，内置 DSH 0.1.2-rc.1）。内置 DSH 版本必须匹配，否则停止安装。请自行打开 DSHA 历史版本下载页面，找到 v1.2.0-rc1.4，展开 Assets，下载适合手机系统的 APK；不要下载 Source code。

安装失败时

  • 先保留最前面的具体错误与文件路径，不要只截取最后一句“失败”。
  • 无法打开网页：检查服务是否运行，并使用含鉴权信息的完整地址。
  • 能打开但不能生成：先检查模型服务配置和服务返回的错误。
  • 一键命令仍无法使用：查看手动安装说明。

更多说明见常见问题与排错日志。不要公开模型密钥、鉴权链接或私人剧情。

支持范围怎么理解

能导入一张卡，不等于它依赖的全部第三方脚本都能执行。我们分别说明资源的导入、编辑、展示和运行支持，不用“全面兼容”代替具体条件。

  • 人物卡支持 PNG 导入和 JSON 导出，目前不提供 PNG 导出。
  • 世界书保留部分高级字段，不等于完整复现原酒馆的全部触发规则。
  • 正则、MVU 和前端美化取决于人物卡的结构，以及所依赖的脚本和宿主接口。
  • 默认建议使用内置预设。要调整文风和写作规则，优先修改人物卡或使用 Guide；外部预设可能改变系统行为。

从哪里开始

如果正文中的状态栏经常掉格式，可以按需转换为 MVU 版。正常工作的卡不需要转换。

游玩模式

从第一局开始，认识眼前的界面和操作。无需先学会所有设置，也不用先制作自己的卡。

实际应用截图 · DSH Tavern v1.9.0 · 2ac3164。样例说明 ↗ · 下载样例人物卡

开始第一局

  1. 完成安装，在 DSH 中配置文字模型服务。
  2. 导入一张 PNG 或 JSON 人物卡，选择新建游玩。
  3. 预览开场白，按需要选择开场并设置玩家称呼。
  4. 输入自己的行动，或选择一个候选、修改后发送。

没有外部预设也能开始；用户画像、生图和后台独立模型都可以先不管。

认识游玩界面

界面区域在这里做什么
左侧历史找到并继续已有游戏，管理对话
中间正文阅读故事，查看当前回复和正文操作
输入框与候选输入行动和对白，选择、修改或重新生成候选
右侧酒馆状态查看 Guide、人物状态，以及已绑定剧本的进度

玩过几轮之后

  • 重新生成候选：换一组行动建议，不改写已经生成的正文。
  • 重写正文：直接重新生成，或填写意见后重写当前回复。
  • 回退当前回合：退回当前回合，不是任意历史节点的存档树。
  • 剧情指导 Guide：为当前游戏添加持续生效的要求。
  • 人物状态与变量回执：查看本轮结果；结算失败可单独重试。

跟随一份剧本游玩

导入小说、大纲或剧本，绑定人物卡后新开一局。故事会参考当前进度附近的片段，你仍然可以自由行动、偏离主线。

右侧可以查看进度和参考片段。进度展示不是跳章按钮。

本局设置

点击游玩顶部“本局设置”，调整本局称呼、预设、用户画像、后台模型和功能开关。打开本局设置完整说明。

全局设置：通用显示、压缩与生图服务

入口：左下角“设置” → “DSH Tavern”。这里管理通用选项；后台模型和任务开关请在上方介绍的本局设置中调整。

正文分色

开启后，引号内对白与斜体分别着色，普通文字保持原色，保留人物卡已有配色。点击色块设置对白和斜体颜色，“恢复默认配色”恢复自动适配深浅背景的颜色。

颜色修改即时应用，只保存在当前浏览器，不改变存档或发给模型的文字，也不跨设备同步。

上下文压缩

默认手动，也可选择每 N 轮自动压缩，或上下文达到指定百分比时自动压缩。轮数范围为 1–1000，百分比范围为 10–95%，百分比是估算。

修改后点击“保存压缩设置”，下一个安全边界生效。自动压缩在剧情后台结算后协调前后台，不删除原始剧情记录。重写同一轮、工具调用和生图不计轮数；模型窗口未知时可改用轮数模式。详见压缩与检索配合。

生图服务配置

在提供场景生图能力的版本中，配置渠道、服务地址、密钥及对应参数，按渠道检查连接或读取模型。这里设置的是服务连接，不是给每局自动生成图片；是否在当前游戏开启生图，由本局设置决定。详见生图配置。

DSH 自身设置

文字模型服务在“设置 → 模型”配置；语言、外观、字号及 Desktop Profile 等由 DSH 对应设置页管理。它们与插件的“系统提示词库”不是同一个入口。

保存和继续故事

通过左侧历史对话继续游玩，也可以导出纯对话 TXT，保存玩家与角色的正文。日志导出用于排错，与故事导出不同。

卡片模式

把不合口味的内容改成自己喜欢的样子。人物卡、世界书、预设和剧本，都可以通过对话来制作与修改。

实际应用截图 · DSH Tavern v1.9.0 · 2ac3164。样例说明 ↗ · 下载样例人物卡

认识卡片工作台

卡片模式不是游戏正文窗口，而是与 Agent 一起处理资源的工作台。选择要做的任务，在中间讨论修改，在右侧查看和引用资源。

界面区域用途
起始任务修改人物卡、世界书、预设或剧本；从素材制卡；空白开始
中间对话说明要求、讨论方案，确认后让 Agent 写入修改
右侧资源库管理人物卡、世界书、剧本、预设、用户画像、Skill 和系统提示词
工作台历史继续之前的制作与修改，与游玩历史分开管理

通过对话修改不喜欢的内容

  1. 选择修改任务和目标资源。
  2. 告诉 Agent 哪些内容不喜欢，希望怎样调整，以及哪些设定要保留。
  3. 查看建议，确认修改范围后再写入工作版。
  4. 查看修改结果；人物卡可新开一局体验。

例如：“保留人物的身份和背景，但把过于强势的性格改得更克制。先告诉我你准备改哪些地方。”

这套方式同样适用于世界书、预设和剧本，不只是人物卡。

从小说和剧本中提取新卡

选择一份或多份素材，说明想提取的人物、相关设定和保留范围。与 Agent 讨论、确认后制作新人物卡，不需要从零填写所有字段。

资源库：在右侧查找、管理和复用内容

在卡片模式打开右侧对应标签页。没有显示时，从右侧的新建标签页入口选择需要的库。库中保存的是可复用资源；选中查看、引用到对话、应用到游戏是不同操作。

人物卡库

保存角色设定，是开局和改卡的入口。可以批量导入 PNG / JSON，搜索与筛选卡片，查看、编辑字段，管理世界书和剧本绑定，重命名、删除或导出 JSON。

要让 Agent 修改，先引用目标卡，再说清修改要求；要开始游戏，从卡片新建游玩。修改工作版不等于所有旧游戏已同步更新。详见人物卡字段与原版恢复。

世界书库

管理独立世界书和人物卡内置世界书。可导入、导出、查看和编辑条目，调整启用状态与触发条件，管理人物卡关联，也可引用给 Agent 修改。

世界书存放故事背景与规则，不是已经发生的游戏记忆。保存高级字段不等于完整执行原酒馆全部规则。详见世界书库。

剧本与素材库

保存小说、故事大纲和写作教学材料。可导入、查看、重命名、删除和引用素材，也可以把剧本绑定到人物卡。

引用素材可以交给 Agent 抽取人物、修改剧本或创建写作 Skill；只有绑定剧本并用于开局，才是剧本游玩的来源。查看页用于阅读，正文修改交给 Agent。详见导入素材。

预设库

管理外部提示词方案。可导入、导出、重命名、删除，编辑提示词条目的内容、角色、顺序和开关，以及预设正则。

“新游戏默认预设”用于之后开局；正在玩的游戏在顶栏“本局设置”选择预设。默认可以不使用外部预设，外部预设可能明显增加思考时间和延迟。详见预设编辑与正则编辑。

用户画像库

保存多份长期偏好，例如分别用于轻松日常和严肃剧情。通过“查看画像”选择库中项目，用“新建”“重命名”管理名称；进入访谈建立画像，或查看、编辑已确认内容。

在库中切换查看或保存修改，不会自动改变当前游戏。当前游戏使用哪份画像，在“本局设置”中选择；库中内容更新后，可在那里检查版本并应用最新内容。新游戏默认使用方式与本局选择分开。详见用户画像完整教程。

Skill 库

保存 Agent 可重复使用的方法。列表区分内置与自建 Skill，按用途分组；可以拖动调整用途，点击名称阅读正文及参考资料，也可编辑、预览、保存或删除。

写作 Skill 用于指导前台表达，其他 Skill 用于对应任务。库中管理方法和用途，本局设置控制当前游戏的写作 Skill 开关；关闭后不会删除已载入历史的内容。详见创建写作 Skill与Skill 管理。

系统提示词库

管理程序开放给用户调整的内置提示词。选择条目查看和编辑，保存后用于相应生成流程；可导入、导出整套 JSON，或恢复默认。

它与外部预设库不同，也不是本局 Guide。更新程序保留自行保存的修改，但主动导入整套配置或恢复默认会覆盖相应自定义内容，操作前可先导出备份。普通文风要求优先放在 Guide 或人物卡，不熟悉内置规则时保持默认。详见系统提示词。

引用、绑定和修改有什么区别

引用是把资源交给当前工作台讨论；绑定是让资源与人物卡建立使用关系；修改则会改变对应工作版。引用到对话，不等于已经绑定到游戏。

导入时保留人物卡原版，日常修改工作版。需要恢复时，可请 Agent 恢复人物卡原版；这不是所有资源都具备的任意版本恢复功能。

帮助与维护

安装、数据和排错的辅助说明。遇到问题时查阅，不需要按顺序阅读。

遇到问题时

先查看并复制具体错误，再选择对应的处理方法。清除提示不等于修复问题；连接成功也不等于真实生成一定成功。

  • 正文或展示异常：交给卡片 Agent 调试。
  • 状态没有更新：查看回执，按错误提示重试结算。
  • 图片失败：区分生成失败与保存失败。

如何绑定多个世界书？

在人物卡详情的世界书区域，点击列表下方的“＋ 新增绑定”，选择世界书后点击“确认绑定”。已绑定的世界书按顺序列出，点击书名可以打开，也可以调整顺序或逐本解绑。同一本书可以被多张人物卡使用。

新开局时，系统将这些书合为一份本局世界书，以第一本作为主书。已有世界书快照的存档保持原有内容；导出人物卡会包含合并后的世界书。

多本世界书可能相互冲突，引发异常。系统不会自动协调设定或初始化变量冲突；需要整理时，可以让卡片 Agent 协助修改世界书。操作入口见世界书绑定。

为什么没有独立的 user 人设？

作者认为，把 user 人设作为跨人物卡的统一设定，也是原酒馆的设计失误。玩不同人物卡时，玩家可以扮演完全不同的人：这张卡里是侦探，另一张卡里可以是学生，身份、背景和人物关系应当跟随具体人物卡。

建议通过卡片 Agent，把想扮演的 user 人设写入人物卡。例如：“我想在这张卡里扮演一名初来小镇的医生，请把我的身份、背景和与其他角色的关系写入人物卡。”具体操作见修改人物卡。

如果希望长期保留叙事风格、互动方式等个人偏好，可以使用用户画像。建立并确认画像后，在右侧用户画像面板开启新游戏默认启用，让新游戏注入这些长期偏好；已有游戏不会自动变化。

设置用途与生效范围
玩家称呼修改后用于后续内容，不重写已有正文
当前预设为本局选择外部预设，或不使用外部预设；影响后续正文

人物姿势结算控制后台是否总结人物位置、动作和姿势
联网搜索允许本局前后台按需查外部资料，后续请求生效
