# DSH Tavern v2.1 变更记录

本次更新重点是适配 **DSH 0.1.5-rc.2**，补齐新宿主下的会话历史读取、正文编辑、重新生成与回退，并改善旧存档迁移和安卓页面兼容性。

## 安装与升级

安装方式和命令沿用原有流程，适配版本更新如下：

| 安装方式 | v2.1 要求 |
| --- | --- |
| 命令行 | 安装器准备独立的 DSH 0.1.5-rc.2，使用固定依赖锁文件 |
| DSH Desktop | Desktop 2.0.13，内置 DSH 0.1.5-rc.2 |
| Android / DSHA | DSHA 0.1.5-rc2，内置 DSH 0.1.5-rc.2 |
| Windows 一键安装 | 使用 Desktop 2.0.13 对应的新安装包 |

已有 Desktop / DSHA 用户需要先使用匹配的宿主版本，不能只更新酒馆并继续使用旧宿主。升级前备份资源和存档；新宿主写入的存档不能直接交给旧宿主读取。Android 仍属于实验性支持，独立酒馆 APK 暂未提供。

## 新宿主适配与旧存档

- 在酒馆内加载针对固定宿主版本的会话补丁，不修改官方 DSH 包文件；前后端完成握手后才开放正文替换、重新生成和回退。
- 适配会话持久化、查询和网页历史读取，避免替换正文后出现存档能写入、页面却无法读取的问题。
- 旧存档迁移保留备份，按宿主正式格式编码文件头；修复迁移后部分会话被列表忽略、同步超时的问题。
- 修复后台消息回退时丢失继承边界、失败后无法按原边界重试的问题。
- 编辑历史正文后使旧姿态与后台历史失效，避免继续使用编辑前的状态。
- 补齐旧 Android WebView 缺少的浏览器 API，修复部分模拟器中对话区域空白的问题。

## MVU 转换与人物卡美化

- 增加专用 MVU 转换、预检和磁盘验收工具，复制完整原卡并按明确清单清理，保留原卡。
- 转换方案支持增量修改、版本校验和冲突提示，减少重复传输长文本和重复调用。
- 原卡的 HTML/CSS 美化由工具直接固化，模型只提供变量映射；保留支持范围内的渐变、图标、布局与折叠内容，避免被重写成默认面板。
- 对脚本或动态属性等暂不支持的外观明确报错，保留原视图，不静默删除美化。
- 修复开场状态面板在模板同步时丢失的问题；补充资源库删除副本后同名重建的验证与操作规则。

## 游玩、资源库与界面

- 恢复完整提示词模板设置与世界书 EJS 编辑入口，区分全局设置和当前游戏操作。
- 增加损坏存档的纯文本历史救援，并保留最后有效的 MVU 快照。
- 候选项支持追加到输入框和自定义收起时机，保留展开状态。
- 剧本支持按轮配置读取篇幅，并按原文位置显示进度。
- 世界书库增加排序；优化条目编辑布局，支持在游戏中应用世界书更新。
- 修复会话重命名持久化、新游戏人物卡列表刷新，以及侧边对话的恢复和历史边界。
- 长对话采用可见回合窗口，减少离屏卡片扫描和重复历史处理；历史扩展由用户主动触发。
- 改善沉浸模式、长卡片展开、预设拖动和图片工作台布局。
- 隐藏顶部“在应用中打开”与原生日志导出菜单，保留酒馆的本局设置、沉浸模式和导出。

## 安装与稳定性

- Windows 包管理使用独立 Node，保留子进程失败信息，改善重装恢复并减少控制台窗口弹出。
- 显式保留卡片 Agent 的文件工具：`read`、`write`、`edit` 与 `str_replace_editor`，不依赖 Web minimal 的默认工具组合。
- 加强后台结算失败、压缩保护和重试处理，保留失败任务的身份与恢复边界。
- 修复稀疏预设转换、资源重命名时间戳、远程卡片脚本顺序及静态资源加载问题。

**v2.1 是最后一次 DSH 本体升级适配。此后固定 DSH 0.1.5-rc.2，不再跟随上游升级；功能与必要修复在酒馆及固定基线上维护。**
