# DSH Tavern v2.2 变更记录

本次更新重点是长对话性能、失败回合恢复，以及手机远程游玩的稳定性。新增独立 Android APK，完善已有游戏中的人物卡更新，并修复多端状态栏、后台结算和旧存档迁移问题。

## 游玩与失败恢复

- 新增失败回合原样重试：重新发送本轮输入，保留上一轮已完成的正文。
- 统一失败清理、正文重新生成和回退的消息归属判断。修复模型只返回思考过程后，因历史系统提示词更新而误报“模型消息面不是连续区间”、无法继续清理的问题。
- 清理失败残留时保留历史正文、世界书和系统提示词；重启后仍可从存档重建恢复边界。无法确认消息归属时继续阻止清理，避免误删其他回合。
- 修复后台 Agent 释放后回退入口不可用、回退与撤销后轮次映射及操作按钮未及时刷新的问题。
- 向上滚动可继续加载更早的游玩回合。
- 修复切换预设后当前选择未正确显示的问题。

## 长对话与后台结算

- 减少状态轮询、会话检查、诊断、脚本提示词和后台配置读取中的完整聊天复制，降低长对话的内存占用与重复处理开销。
- 优化 MVU 检查点、变量增量读取与持久化；修复增量缓存与实际保存内容不一致的问题。
- 调整 MVU 任务领取、超时判断和中断后的重新交付，减少后台已完成但状态栏迟迟不更新的情况。
- 后台结算期间暂停重复的模板展示轮询，减少争抢资源和反复执行。
- 提高服务端模板进程的堆内存上限，并保留退出原因和错误输出，便于定位大卡片执行失败。
- 上下文默认在压力达到 50% 时触发压缩；补充超大压缩请求的有界摘要恢复，保留旧存档迁移后的压缩边界。

## 人物卡、MVU 与模板

- 完善“将人物卡更新应用到已有游戏”：保留游玩历史，并同步当前卡片配置和相关展示；修复更新后原始状态栏模板混入正文的问题。
- 修复 MVU 转换中的字段定义、不同开场变量初值保留问题；没有原始外观的卡片可由卡片 Agent 设计状态面板。
- 修复部分模型接口下 MVU 变量值类型丢失，以及延迟脚本写入脱离结算事件的问题。
- 改善开场脚本加载顺序、旧 iframe 绑定清理和 MVU 初始化，减少长对话中重复请求会话数据。
- 区分普通文本格式化与模板展示，避免无效模板让正文膨胀或误接管显示。
- 补齐部分卡片使用的 `generateRaw` 参数和模拟流式事件兼容；修复独立 `/trigger` 的空提示词问题。
- 合并脚本、世界书和预设编辑的启动入口，完善卡片诊断错误信息。

## 手机与多端访问

- 修复电脑运行酒馆、手机远程访问时，状态栏中的装备、任务等按钮无法点击的问题。
- 次要浏览器可读取实时 MVU 状态，减少多端状态栏数据不一致。
- 切换对话时卸载不活跃的人物卡面板，避免旧卡脚本继续干扰当前对话。
- 恢复手机上的原生右侧栏入口，适配并固定使用 `dsh-better-sidebar 0.19.1`。
- 统一卡片库与部分设置界面的暖色主题，改善深色模式配色，并将字号上限提高到 32px。

## Android 与安装更新

- 新增独立 DSH Tavern Android APK：首次启动联网安装运行环境和酒馆，无需另装 DSHA 或输入安装命令。
- 独立 APK 要求 Android 11 及以上、ARM64；与原版 DSHA 数据独立，不会自动迁移旧聊天。Android 仍为实验性支持，目前安装验证来自 MuMu Android 12，尚未完成实体手机验证。
- 修复 Android 更新遇到残留进程信息或损坏 pnpm 时的恢复问题。
- Windows 安装支持更新已有酒馆并停止旧运行环境，改善代理警告、只读文件清理、环境变量大小写重复和子进程窗口弹出问题。
- 修复 Desktop 下部分 pnpm 版本的安装兼容问题；根据宿主选择移动端插件，避免重复加载。
- 精简运行包中的开发资源、文档和宣传图片，修复依赖补丁移除后的运行包分发问题。

## 验证与升级说明

- 补充真实 DSH 与浏览器 E2E，覆盖新开游戏、刷新恢复、卡片更新、预设切换、候选项、正文编辑、重新生成、回退与撤销、上下文压缩及失败回合恢复。移动恢复流程包含 Chromium 窄屏触控测试，不等同于实体手机全机型验证。
- **继续固定 DSH `0.1.5-rc.2`，不要求升级 DSH 本体。** Desktop / DSHA 沿用 v2.1 对应的宿主版本。
- 更新后重启酒馆；Desktop 用户完全退出并重新启动 DSH Desktop，再刷新已打开的浏览器页面。
