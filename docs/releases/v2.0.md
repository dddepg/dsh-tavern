# DSH Tavern v2.0 变更记录

这次更新的重点，是让已有功能在真实使用中更可靠：重新生成遇到异常后能恢复，切换对话不轻易打断任务，长对话减少重复处理，人物卡和模板更准确地按原有设定运行。同时补充完整上下文查看、世界书主动补查，以及新游戏默认模型和写作技能设置。

## 重新生成与回退：补齐异常恢复

- 修复重新生成失败后出现“临时消息不是连续区间，无法安全清理”的问题。清理按消息来源和替换关系判断，避免把旧上下文或原正文误算成本次临时消息。
- 修复手动停止后恢复冲突，以及残留恢复状态误清理下一轮正常消息的问题。
- 重新生成增加分阶段恢复：新正文尚未提交时恢复原剧情；新正文已提交、模型上下文尚未保存完成时，保留新正文并补完上下文。
- 支持进程意外退出、消息保存失败后的恢复和重试；重复恢复不会再次插入同一份替换正文。
- 失败恢复保留生成期间保存的 Guide 等非剧情设置，不再整份覆盖成旧配置。
- 服务端增加普通生成、重新生成与回退之间的互斥检查，拒绝过期的重生成请求，减少多页面或状态延迟造成的交叉执行。
- 完善回退后的正文、变量、聊天局部状态和可见消息同步；修复重新进入会话、手动压缩后部分“撤销回退”误失效的问题。

## 上下文压缩：更稳，也更容易看懂失败原因

- 修复酒馆内部空消息标记导致上下文压缩失败的问题，压缩请求不再携带这些占位内容。
- 改善后台上下文超限后的自动压缩，结合模型窗口和输出预留空间判断容量。
- 修复默认模型容量读取及压缩恢复后警告未清除的问题。
- 压缩失败显示本次操作的具体原因，区分摘要未缩小、等待空闲超时等情况，不再只给出笼统错误或一律建议重试。

## 提示词模板：执行迁到服务端

- 完整提示词模板改由服务端独立进程执行，减少对当前网页、模板 iframe 和页面就绪状态的依赖。开局、世界书处理、正文和后台任务使用同一套服务端执行入口。
- 增加会话隔离、串行执行、空闲回收、超时终止及取消处理；失败后不会盲目重跑已经开始的模板，降低重复执行副作用的风险。
- 修复进程通信中的 JSON、变量作用域和上下文语义问题，保留逐条模板求值及状态刷新。
- 优化批量模板调用、资源投影和未变化数据的传输，减少逐条处理大世界书时的重复开销。
- 补齐 Node 24 权限参数适配，以及局域网 HTTP 下部分运行时和聊天导入兼容问题。

## 世界书：增加主动补查，减少重复注入

- 正文 Agent 和共享后台 Agent 可搜索、阅读当前绑定世界书，补查自动召回之外的条目。搜索支持分页，阅读返回渲染后的正文。
- 前台本轮已成功读取的条目，会交接给后台结算、候选生成和人物设计任务，减少重复查阅与前后台信息脱节。
- 大世界书候选池增加 BM25 词面预筛选，并纳入当前玩家输入，减少无关候选带来的处理负担。
- 原生游玩的 EJS、随机及其他动态世界书内容不再放进固定前缀。内容仍正常求值；结果相同不重复发送，变化时追加新快照，清空时明确使旧版本失效。
- 完善动态快照在回退、失败重生成、分支、历史导入和压缩后的处理；应用人物卡更新时同步刷新世界书快照。

## 人物卡、预设与 MVU 兼容

- 修复部分旧式扁平人物卡可读取、可修改，却在校验时被误报格式错误的问题。
- 收紧卡片编辑 Agent 的任务范围，优先处理目标人物卡及相关资源，避免简单修改失败后无边界搜索其他人物卡和工作区。
- 新增人物卡复制工具，复制 PNG 人物卡时保留原始画面；完善温和改写及 MVU 转换任务指引。
- 修复预设宏和正则处理顺序，让预设正则先作用于人物卡渲染，减少正文、状态栏和实际请求之间的差异。
- 补充 SillyTavern 局部变量到持久聊天状态的桥接。
- 改善 MVU 事件领取、脚本回执、执行续期和当前轮 Helper 设置交接，减少重复执行、保存冲突和切换对话后任务被提前释放。
- 保留脚本原始错误码、超时原因与嵌套调用来源；不支持的卡片处理链在发送正文前明确报错。

## 完整上下文与诊断

- 对话页新增“完整上下文”，可查看最近一次实际模型请求的系统提示词、工具定义和有序消息，支持折叠查看及 JSON 导出。
- 后台 Agent 和图片 Agent 也可查看最近请求上下文，便于核对实际发送了哪些信息。
- 调整预设、来源及请求元信息的展示，保持请求内容顺序，减少嵌套滚动和布局干扰。
- 诊断包补充会话预设与正则处理链信息，优化模型请求、图片尝试和 MVU 诊断记录的存储。

## 日常操作与默认设置

- 支持设置新游戏的默认前台模型、后台模型和写作技能。已有游戏保持当前配置，也可在本局单独调整。
- 统一全局和本局的写作技能开关；模型设置中补充推理强度建议。
- 用户画像改为一份持续更新的文档，简化为单一内容编辑与直接保存。
- 系统提示词设置增加图片 Agent 提示词；升级迁移时保留用户自定义提示词。“系统附加指令”最终默认关闭，可按需启用。
- 新建酒馆会话默认使用完全权限模式，减少反复审批。
- 切换页面时保留开局准备和进行中的任务；未选中的对话界面保留约十分钟，减少来回切换时的重复加载，并修复切换后旧视图串入新会话的问题。
- 使用页内确认框替代原生确认弹窗，改善 Desktop 兼容性；修复侧栏拖动条遮挡滚动条、部分人物卡触屏滚动和设置布局问题。

## 长对话性能与存储

- Chat 快照改用压缩存储，增加有上限的聊天缓存和版本增量复用。
- 变量更新、回执、名称同步和请求结果记录尽量只保存变化部分，减少整段历史及大请求正文的反复复制、序列化和写入。
- 后台任务复用已在上下文中的世界书候选正文和剧本窗口，减少重复发送，同时保留既有请求前缀。
- 减少重复的模板资源投影、指纹计算和任务回执数据；正文增量显示不再因无关状态更新而反复全量重建。
- 修复中断快照及旧数据迁移恢复、消息替换计量和历史预设识别中的若干问题。

## 安装、更新与说明文档

- 更新检查优先向 GitHub 核实最新版本，再使用 CDN 回退，减少 CDN 缓存导致的“误报已是最新”。
- 启动时检查 DSH 适配版本，明确提示当前宿主是否匹配。
- 修复 Windows 启动器持久保存、快捷方式及旧安装目录隐藏问题；改善 Android 启动超时后的清理与回滚。
- 避免 pnpm 更新检查阻塞已经完成的安装。
- 更新安装、资源库、本局设置与高级功能教程；示例资源统一整理到 examples。

## 升级说明

- Windows 附件沿用已核验的 Desktop **2.0.5** 在线安装器，首次启动联网安装当前兼容的最新版酒馆；它不是新的 Desktop 构建。
- 当前仍只适配 **DSH `0.1.2-rc.1`**。v2.0 是酒馆版本，不代表已经适配更高版本 DSH；TTS 也尚未包含在本次更新中。
- 服务端模板执行不等于所有人物卡都可以脱离浏览器运行：人物卡展示脚本、MVU 和 Helper 的浏览器运行时仍然保留。
- 动态世界书快照机制针对原生游玩；已有会话升级后，动态内容从固定前缀迁出，首次请求前缀会变化。本文不承诺所有模型、人物卡都达到相同速度或缓存命中率。
