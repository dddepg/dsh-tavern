# DSH Tavern v2.3 变更记录

这一版重点完善人物卡创作：增加改卡记忆，简化 MVU 转换与变量编辑，让人物卡修改可以同步到已有存档。同时改善前台变量查询、主题外观、安装更新和长对话性能。

## 人物卡修改与记忆

- 卡片模式内置改卡记忆，记录用户偏好、遇到的错误和可复用的修复经验；游玩模式不额外引入改卡记忆。
- 修改人物卡入口简化为 `/edit-card`，附带目标卡和用户要求；按需读取人物卡及实际绑定的世界书，优先做局部修改。
- 将错误经验写入改卡记忆，不再默认生成 Skill。改卡交付以保存和自动校验为依据，不强制要求用户真实游玩验收；静态验证与运行效果仍分别说明。
- 增加脚本折叠查看，修复扩展标签重叠、已删除副本仍被当作旧目标等问题。

## MVU 转换与变量编辑

- 支持增量草稿，分批填写字段、更新规则、各开场初值和外观，校验后统一提交。
- 简化工具参数，记住当前草稿并提供短引用，减少重复传递路径和修订号。
- 修复 `openingStates` 返回非无损 JSON 的问题；加强字段结构、继承和多开场一致性检查，提供明确的修复提示。
- 支持修改已有托管 MVU 卡的变量结构、初值及规则；新增字段可通过局部面板组件自动分配捕获编号，无需重写整份 HTML。
- 修复生成面板重复显示变量路径的问题，并保留现有布局和无关人物卡内容。

## 已有存档与游玩连续性

- 应用人物卡更新时，新增字段补入初值、已删除字段同步移除；已有字段保留游玩中的值，不用初值覆盖进度。
- 保留运行中产生的动态数据，并对不兼容的类型变更进行检查，避免静默破坏存档。
- 重新加载人物卡时同步开场中的 `initvar` 和原生会话投影，修复变量已更新但轨迹仍显示旧初始化内容的问题。
- **新增前台变量读取工具 `tavern_read_variables`**：游玩时，前台模型可按需分页查询有哪些变量、搜索变量路径、读取具体值；对象按层展开，长文本分段返回，避免一次把全部变量塞进上下文。工具只读，不修改存档；返回结果附带结算状态，便于识别后台尚未完成时的上一轮已保存值。

## 外观与日常操作

- 原生侧栏“开始”页按本局、资料库、偏好、其他分组，使用随主题变化的图标卡片，支持窄侧栏与长标题换行。
- 整合共享主题与强调色，修复正文对话高亮未跟随外观设置的问题。
- 写作 Skill 开关可动态生效，避免重写已有历史、影响既有请求前缀缓存。
- 支持本局状态栏位置设置，修复缓存视图未及时反映位置变更的问题。
- 修复切换会话后旧卡悬浮窗残留，以及部分视口布局面板被压成细条的问题。
- 自动化测试会话不再混入普通游玩历史，避免点击后反复等待 Session 列表同步超时。

## 性能、恢复与安装更新

- 减少长对话内部读取、场景图片轮询及 journal 重放中的整档复制，合并重复冷读取，保留读写副本隔离。
- 后台模型长时间无进展时提供停止与恢复入口；退役后台 Agent 持久化记录，避免重试后堆积“可继续”的旧会话。
- 修复隐藏种子消息时撤回已物化节点导致的核心约束异常（#111），并处理 #109 的长档读取开销、#110 的后台 Agent 堆积。
- Windows 安装更新补充阶段、进度与诊断信息，减少重复下载，改善 Node 镜像回退和已有运行环境复用。
- 修复 Desktop 更新中的路径和 pnpm 定位问题；提供标准插件安装方式，详细说明移入文档网站。

## 更新与验证说明

DSH 核心仍固定为 `0.1.5-rc.2`，本次不升级核心基线。已有用户通过 Tavern 的更新入口获取新版，更新后重启服务并刷新页面。

发布前全量自动回归：2754 项通过、0 失败、10 项跳过；客户端与标准插件构建产物一致性检查通过。此前已完成针对性自动测试、MVU 变量结构与开场更新 E2E、真实模型变量查询验证，以及原生“开始”页浏览器显示与跳转验证。性能数据来自本地合成基准，不代表所有用户长档的 CPU 占用或网络断连均已消除；缺少原卡的面板问题仅验证了同类布局复现。

本次 GitHub Release 不重新打包桌面 EXE 或 Android APK；已有在线安装器仍通过安装或更新获取 Tavern 新版。npm 包发布节奏与 GitHub Release 独立。
