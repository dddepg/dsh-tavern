# CLI 的 Pocket 手机访问

在主界面的 **设置 → 手机访问** 中切换“启用 Pocket 手机访问”，然后点击“应用并重启”。操作会准备或移除 Profile 中的 Pocket 依赖并重启酒馆，可能需要下载依赖；正在运行的任务会被中断。

开关保存后，页面会分别显示保存的选择和当前运行状态。关闭后必须应用并重启，Pocket 才会停止监听。若正在通过 Pocket 访问，连接会断开，请使用主界面地址重新进入。

新安装 CLI 默认关闭。旧版安装曾自动加入 Pocket，因此升级时，没有明确开启记录的 CLI 也会关闭 Pocket；需要继续使用时，在上述设置里重新开启。GUI 选择保存在 Profile 的 `dshTavern.cliPocketEnabled`，后续安装和更新保留选择。删除包名不再是关闭入口的必要步骤。

Pocket 的公网隧道默认关闭；这不等于没有网络监听。关闭 Pocket 后，“手机访问”页面仍会保留服务开关，方便重新开启。

开启后，Pocket 默认监听 `0.0.0.0`（全部网卡，端口以“手机访问”页面为准，可在 Pocket 配置中调整），使用独立 PIN 认证。公网能否访问取决于防火墙和网络；它不继承其他 Web 登录插件的认证。此开关仅控制 Pocket，用户自行安装的其他网络入口不受影响。

Desktop 和 Android 不显示这个 CLI 开关，沿用其现有宿主配置。此次验证覆盖 CLI 设置、配置迁移与重启流程，不代表完成公网 VPS 安全审计。
