# 局部写入的复制放大优化

`applyJsonChangesShared` 原先在 set 字段时先深拷旧子树，再以新值替换；同一批补丁还会反复浅拷贝公共祖先（包括全部消息引用组成的数组）。

本轮直接克隆 set 的新值，用每次调用独立的 WeakSet 跟踪本批分配的祖先；只有这些自有对象允许复用。splice 同样复用本批分配的数组，新增项仍分离。原始内部状态、调用者传入的新值均不会被修改；中途非法操作抛错不会改变原状态。外部 read/update 隔离和持久化格式不变。

## 验证

191 项相关测试通过，包括 Journal/Persistence、补丁重叠与失败原子性、脚本派发、MVU 结算恢复、时间线及视图读取。新增旧子树访问回归在上一提交的实现上失败，新实现通过。

| --- | ---: | ---: |
| 每批替换 100 个楼层变量快照 | 99.8 ms | 4.9 ms |
