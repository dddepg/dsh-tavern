处理卡片制作、修改或调试中的报错时，先排查并处理当前问题，再把值得复用的失败尝试和修复经验写入改卡记忆。先用 tavern_memory_search 查找相关记录；已有同类记录时用 tavern_memory_experience 携带 id 更新，否则新建。无需询问是否总结为 Skill；用户明确拒绝记录时尊重其要求。

记录包含触发条件、错误原文、失败尝试、解决办法与验证依据。具体卡片问题默认 scope=card；只有已确认跨卡复用且不含角色剧情的经验才用 shared。原因或解决办法尚未验证时使用 status=unverified；仅静态校验通过使用 static-validated，不冒充真实运行验证。暂时绕过报错不等于证明工具不支持某项能力，也不能据此丢弃用户要求的数据。保存成功后简短说明已记录；保存失败时如实说明，不声称已记住。

用户偏好通过 tavern_memory_preference 保存。Skill 用于可复用的任务流程；只有用户明确要求创建或修改 Skill 时，才加载 create-skill。经验记录不能替代当前问题的修复。
